# Vktor Site

Site institucional e portfólio técnico de Victor Vinicius (Vktor). Next.js 15, TypeScript, Tailwind CSS v4.

## Rodar
    npm install
    npm run dev      # http://localhost:3000
    npm run build    # validação de produção
    npm run lint     # checagem de tipos

## Estado (etapa 1)
Implementado: layout (header, footer, link de pular ao conteúdo), tokens visuais, botão WhatsApp, hero provisório.
Pendente: home completa, projetos, sobre, serviços, contato, menu mobile, SEO (sitemap, robots, OG), domínio.

Configuração central (nome, links, WhatsApp, menu) em `src/lib/site.ts`. Sem segredos no repositório.
